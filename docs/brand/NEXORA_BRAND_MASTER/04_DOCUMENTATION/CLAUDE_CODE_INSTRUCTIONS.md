# NEXORA — INSTRUCCIONES PARA CLAUDE CODE

Antes de modificar branding:
1. Leer la carpeta `docs/brand/NEXORA_BRAND_MASTER/`.
2. Tratar el logo NEXORA y sus variantes como activos oficiales de producto.
3. Tratar SAP Icons como biblioteca externa y no modificar sus SVG.
4. No crear logos alternativos ni mezclar otras librerías de iconos.
5. Consumir colores y tokens desde la fuente de verdad.
6. Validar desktop, iPhone, PWA, claro/oscuro, login, sidebar, documentos y reportes.

Criterio de terminado: código real, interfaz conectada, tokens centralizados, documentación, pruebas y commit publicado. No declarar el bloque terminado si solo existen archivos aislados.
