# NEXORA — GOBERNANZA DE MARCA

La identidad visual actual es una decisión de producto. El logo NEXORA es propio; la biblioteca SAP es un activo externo.

NO:
- rediseñar el logo en un módulo;
- usar logos anteriores;
- sustituir SAP Icons por otra librería sin decisión explícita;
- alterar SVG SAP;
- introducir estilos de icono mezclados;
- copiar activos propietarios adicionales de SAP.

Referencia de disciplina iconográfica: SAP/Fiori (24×24, área viva 20×20, consistencia de trazo y balance). La implementación de interfaz usa los activos que este repositorio declara como fuente de verdad.
