# NEXORA — Architecture Baseline

## Producto oficial

NEXORA es la plataforma oficial de gestión integral de fondos, proyectos y operaciones.

## Motor técnico

ERPNext/Frappe permanece como motor técnico interno cuando aporta capacidades reutilizables.

## Componentes confirmados

- Plataforma empresarial basada en ERPNext/Frappe.
- Gestión operativa y financiera.
- Auditoría y permisos.
- Experiencia escritorio, móvil y PWA.

## Componentes pendientes de validación

- Inventario completo de DocTypes.
- Endpoints definitivos.
- Mapa completo frontend/backend.
- Eliminación de deuda técnica heredada.

## Reglas de evolución

- No crear sistemas paralelos.
- Mantener compatibilidad técnica.
- No eliminar código sin evidencia.
- Validar cambios antes de producción.
